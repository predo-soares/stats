# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Requires evaluation |
| needs-info | needs-info | Waiting on reporter information |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Create a missing label only when its role is needed. `wontfix` was already present when this configuration was established; the other default names are the selected vocabulary, not a claim they were all pre-created.

PRDs produced with to-prd receive `ready-for-agent` without an additional triage pass.
