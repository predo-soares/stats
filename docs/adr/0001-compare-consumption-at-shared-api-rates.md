# Compare consumption at shared API rates

The dashboard's Cost metric estimates the API-rate value of both Cursor and Codex consumption, rather than adding reported Cursor charges to Codex estimates. Subscription fees and billed charges are separate concepts: a mixed dollar total would obscure that distinction.

Apply one pricing table to both the selected period and its baseline. Historical estimates may change when rates update; this intentionally measures consumption and model mix at consistent rates, rather than reconstructing historical invoices. Keep token accounting independent of pricing so unpriced models retain their token counts and can be valued later. Incomplete prices must remain explicit and must not become zero-dollar consumption.
