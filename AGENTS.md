## Agent skills

### Issue tracker

Publish PRDs and implementation issues to GitHub Issues in `predo-soares/stats`. Before tracker operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical triage roles and label names defined in `docs/agents/triage-labels.md` when creating or triaging issues.

### Domain docs

This is a single-context project. Before planning or changing usage accounting, pricing, collection, or presentation, read `docs/agents/domain.md` for the glossary, specification, and ADR pointers.
